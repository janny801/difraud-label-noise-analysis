# DiFrauD Label Noise Analysis

Dataset Cartography and label noise mitigation for fraud detection datasets.

## Overview
- **Techniques**: Dataset Cartography (confidence & variability tracking), label noise mitigation, hyperparameter optimization (Optuna, Weights & Biases).
- **Models**: SentenceBERT + MLP, GloVe + LSTM, Transformer fine-tuning (RoBERTa / DistilBERT), and baselines (SVM).
- **Data**: Analysis on text fraud detection datasets (`redasers/Unmasking-the-Imposters` / DiFrauD benchmarks).

## Contents
- `DiFrauD_label_noise_analysis.ipynb`: End-to-end training, embedding extraction, baseline comparisons, and evaluation.
